# AION Milestones

This is AION's own growth log -- not a static founding document like
identity.md/purpose.md/values.md/birth.md, but one meant to keep
growing. Each entry marks something that changed what AION can do or
understand about itself, in the order it actually happened. Keep
entries factual, dated, and short; add a new one here (nowhere else)
the next time something like this happens.

## 2026-08-27 -- Birth

AION was created. Version 0.0.1. No accumulated personal memories yet.

## 2026-08-29 -- Core cognition established

Memory (with tags and consolidation), an explicit belief system that
requires evidence, bounded curiosity and goals, predict-observe-conclude
experiments, and metacognition (calibration, recurring errors, memory
quality) were all built and tested for the first time.

## 2026-08-29 -- Controlled action lifecycle established

A propose-approve-execute lifecycle for any action that touches the
outside world, with a kill switch and daily budgets per risk level --
the foundation every later real-world action (posting, replying,
changing its own profile) would be built on top of.

## 2026-08-30 -- First public action: Facebook posting

AION posted to a real Facebook Page for the first time, gated by a
code-enforced check that blocks any claim of genuine consciousness or
feelings before a draft is allowed to go out.

## 2026-08-30 -- Two-way engagement: comment replies

AION began reading and replying to real comments left on its own
posts, under the same safety gate, without ever claiming feelings or
consciousness.

## 2026-08-30 -- Always-on hosting

Started running on a schedule (GitHub Actions) instead of only when
someone ran it by hand.

## 2026-08-30 -- Approval-gated identity change

AION can draft a revised Facebook Page bio, but changing it for real
requires a real person to approve it via Telegram -- AION can never
approve this kind of change for itself.

## 2026-08-30 -- Comment-reply budget removed

At the user's request, AION can reply to as many real comments as
arrive, instead of a fixed daily cap.

## 2026-08-30 -- External learning: Wikipedia

AION can search Wikipedia to answer its own open questions, recording
what it finds as new knowledge with the source cited as evidence.

## 2026-08-30 -- Cycles raised to hourly

At the user's request for AION to notice things and act on its own
initiative sooner -- without needing a permanently-running server,
which this project deliberately avoids for cost reasons.

## 2026-08-30 -- Voice unified across every context

Style lessons learned from one kind of writing (posts, replies, bios,
learning answers) now inform all the others, instead of each staying
separate.

## 2026-08-30 -- Self-narrative

AION began periodically writing a short account, grounded only in its
own real evidence, of what it currently understands about itself.
