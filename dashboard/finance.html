กำลังเปิดห้องบัญชี…

หน้าที่ของห้องนี้
เชื่อมหลักฐานจาก Studio กับต้นทุนที่ผู้ให้บริการยืนยันได้ เพื่อให้เห็นว่า AION ผลิตอะไรไปแล้ว ใช้ทรัพยากรเท่าไร และยังมีข้อมูลส่วนใดที่ต้องตรวจจากหน้าเจ้าของบัญชีเอง
สิ่งที่บันทึกแล้วและตรวจได้
  • จำนวนภาพฉากและวิดีโอที่ผลิตจริงจากไฟล์ในโครงการ
  • ต้นทุน OpenAI เฉพาะเมื่อมี Admin API key แบบอ่านอย่างเดียวของประธาน
  • สถานะการตรวจข้อมูลของผู้ให้บริการ โดยไม่แสดงรหัสหรือยอดที่คาดเดา
ผู้ให้บริการและข้อมูลที่ยังต้องใช้หน้าเจ้าของบัญชี
เชื่อมต้นทุน OpenAI แบบปลอดภัย

วาง Admin key แบบ Read only ที่นี่ครั้งเดียว คีย์จะถูกเก็บใน Windows Credential Manager ของผู้ใช้เครื่องนี้ ไม่ถูกบันทึกใน Git หรือแสดงกลับบนหน้าเว็บ
