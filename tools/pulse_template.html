ระบบสถานะนี้เห็นอะไรบ้าง: สถานะรันจริงของทุก workflow ใน GitHub Actions (repo สาธารณะ) — ว่ารอบล่าสุดสำเร็จ ล้มเหลว หรือกำลังรันอยู่ คำนวณจากภายใน GitHub Actions เอง (ไม่ใช่จากเบราว์เซอร์ของพี่ — หน้าเว็บที่เผยแพร่แบบนี้ถูกแพลตฟอร์มบล็อกไม่ให้ดึงข้อมูลจากอินเทอร์เน็ตได้เอง) แล้วเผยแพร่เป็นไฟล์สาธารณะให้หน้านี้แสดงผลทุกชั่วโมง

สิ่งที่หน้านี้ยังไม่เห็น: คอมเมนต์จริงจาก Facebook หรือรายละเอียดความจำแบบเจาะลึกทั้งหมด — ข้อมูลดิบนั้นอยู่ใน private repo aion-memory-data เท่านั้น ต้องเปิด Observatory ในเครื่อง (Start-AION-Observatory.bat → http://127.0.0.1:8787) เพื่อดูแบบละเอียดที่สุด
