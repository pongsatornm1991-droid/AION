# AION Creator episode 002 — Every Sunrise Is a Message From the Past

Five visual scenes, each held for seven seconds. The factual premise is that
sunlight takes about eight minutes and twenty seconds to travel from the Sun to
Earth. The final two sentences are explicitly AION's reflection, not a
scientific claim.

Source: NASA, “Voyager 1: What Is a Light-Day”
https://science.nasa.gov/mission/voyager/voyager-1/voyager-1-what-is-a-light-day/
