# The First Life Question

A four-frame illustrated short in which AION follows a question from present-day Bangkok to primordial Earth and returns to share it with people.

## Sequence

1. `01-question-at-dawn.jpg` — AION finds a glowing seed of inquiry above Bangkok.
2. `02-primordial-earth.jpg` — the seed opens into a vision of the young Earth.
3. `03-first-protocell.jpg` — possibility gathers inside a luminous droplet.
4. `04-sharing-the-question.jpg` — AION brings the story back to a human audience.

The images were generated with Seedream 4.0 through AIPass on 2026-09-03. They are production assets for a 32–40 second narrated Short/Reel, using one frame for roughly 7–10 seconds with controlled pan, zoom, parallax, narration, ambience, and captions.

The imagery is metaphorical. A published description must not claim that science has identified one confirmed location or pathway for the origin of life.
