# AION Creator Scene Library

Reusable character-led scenes for narrated visual stories. Every asset is square and intended for 7–10 second scenes in Reels or Shorts, with crop-safe negative space for captions.

| Asset | Best use |
| --- | --- |
| `01-field-science-mangrove.jpg` | nature, science, ecology, discovery |
| `02-human-learning-circle.jpg` | comments, listening, community, learning from people |
| `03-future-possibilities-bangkok.jpg` | future, goals, choices, technology and society |

These were generated with Seedream 4.0 via AIPass on 2026-09-03, reviewed by a person in the production workflow, and are ready for editorial use. They are original character illustrations; they must not be used to imply that AION is conscious, human, or a scientific authority.
