# AION Company v2 — แผนปฏิบัติการเดียว

เอกสารนี้คือแผนกลางของบริษัท AION แทนการตีความจาก workflow หรือ
เอกสารเก่าทีละฉบับ ระบบเดิมไม่ถูกทิ้ง: สิ่งที่ผ่านการทดสอบและใช้งานได้
จะถูกรวมเป็นสายงานที่ตรวจสอบได้

## หลักการอำนาจ

- AION เป็น CEO: เลือกหัวข้อ ประสานงาน ตรวจคุณภาพ และเผยแพร่ผลงาน
  สาธารณะที่ผ่าน Quality Gate
- ประธานอนุมัติเฉพาะเงิน/รายได้/สัญญา สิทธิ์บัญชี ข้อมูลรับรอง และการ
  เปลี่ยนขอบเขตความปลอดภัย
- ทุกงานภายนอกต้องมีบันทึกผลและไม่ทำซ้ำเมื่อระบบรันอีกครั้ง

## สายงานบริษัท

| ฝ่าย | ผลลัพธ์ที่รับผิดชอบ | งานส่งต่อ |
|---|---|---|
| วิจัย | หลักฐานและสิ่งที่ยังไม่แน่ชัด | เรื่องเล่า |
| เรื่องเล่า | Hook, คุณค่าต่อผู้ชม, storyboard | ภาพและเสียง |
| ภาพ/เสียง | สินทรัพย์ต้นฉบับและวิดีโอ | คุณภาพ |
| คุณภาพ | หลักฐาน คุณค่าผู้ชม ความซ้ำ และข้อกำหนดแพลตฟอร์ม | เผยแพร่ |
| เผยแพร่ | Instagram, Facebook, YouTube พร้อมบันทึกผล | การเติบโต |
| การเติบโต | สัญญาณผู้ชมและการทดลองคอนเทนต์ | CEO/วิจัย |
| ความจำ | บทเรียน เวอร์ชัน การเก็บรักษา และการล้างไฟล์อย่างปลอดภัย | ทุกฝ่าย |

## แผน 4 ระยะ

### ระยะ 1 — ทำให้ความจริงตรงกัน

1. รวบรวม workflow ที่ซ้ำบทบาทและทำแผนผังเจ้าของงาน
2. ทำสถานะเดียวสำหรับ “พร้อมผลิต / ผ่านคุณภาพ / เผยแพร่แล้ว / ล้มเหลว”
3. อัปเดตเอกสารสถาปัตยกรรมและ Dashboard ให้รายงานจากข้อมูลจริงเท่านั้น

### ระยะ 2 — สายการผลิต Creator

1. หัวข้อ → วิจัย → เรื่อง → ภาพใหม่ → เสียง → Quality Gate → เผยแพร่
2. ทุกตอนมี AION เป็นตัวดำเนินเรื่อง มีแหล่งอ้างอิง และมีคุณค่าต่อผู้ชม
3. ห้ามใช้ภาพเดิมซ้ำเป็นทางลัด และห้ามเผยแพร่เนื้อหาที่ซ้ำหรือไม่มีสาระ

### ระยะ 3 — วงจรเรียนรู้จากผู้ชม

1. รวมผล Facebook, Instagram และ YouTube ตามผลงานชิ้นเดียวกัน
2. ให้ Growth Agent เสนอการทดลองขนาดเล็กจากข้อมูลจริง ไม่สรุปจากโพสต์เดียว
3. ส่งบทเรียนกลับให้ฝ่ายวิจัยและเรื่องเล่า

### ระยะ 4 — ความพร้อมสร้างรายได้

1. พิสูจน์คุณค่าของซีรีส์กับผู้ชมก่อน
2. AION เสนอทางเลือกได้ แต่การขาย ราคา สปอนเซอร์ สัญญา และการรับเงิน
   ต้องให้ประธานอนุมัติทุกครั้ง

## เกณฑ์ “บริษัทครบวงจร”

บริษัทถือว่าครบวงจรเมื่อทุกสายงานมีข้อมูลเข้า งานส่งต่อ สถานะผลลัพธ์ และ
การทดสอบ; Creator episode สามารถเดินถึงการเผยแพร่จริงเมื่อบัญชีเชื่อมต่อ;
และผลผู้ชมย้อนกลับมาเป็นบทเรียนสำหรับตอนถัดไปโดยไม่ต้องจัดข้อมูลด้วยมือ

## งานถัดไปตามลำดับ

1. รวมและลด workflow ที่ซ้ำซ้อน โดยไม่หยุดการเผยแพร่ที่ใช้งานอยู่
2. ทำทะเบียนงานกลางของแต่ละฝ่ายพร้อมสถานะเดียว
3. เพิ่มรายงานความพร้อมบัญชีแบบไม่เปิดเผยรหัสลับ
4. ทดสอบเส้นทาง Creator episode แบบครบวงจรบนช่อง YouTube ที่เชื่อมต่อ
